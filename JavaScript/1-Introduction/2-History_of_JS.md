# History of JavaScript – Interview Questions and Answers

## 1. Who created JavaScript, and when was it developed?

JavaScript was created by **Brendan Eich** in **1995** while he was working at **Netscape Communications Corporation**.  
He developed the first version of JavaScript in just **10 days**.

---

## 2. Why was JavaScript originally created?

JavaScript was originally created to:
- **Make web pages interactive and dynamic**.
- Enable **client-side scripting** so users could interact with the browser without needing to contact the server for every action.
- Complement Java and HTML in Netscape’s vision of a full-stack web platform.

---

## 3. What was JavaScript initially called before being renamed?

JavaScript was initially called **Mocha** during early development.  
It was later renamed to:
- **LiveScript** (during early Netscape releases)
- Finally renamed to **JavaScript** in 1995, as a marketing strategy to capitalize on the popularity of **Java** at the time (though they are unrelated in design).

---

## 4. How did JavaScript become a standard and what role did ECMAScript play?

As JavaScript gained popularity, differences began emerging between browser implementations. To avoid fragmentation:
- **Netscape submitted JavaScript to ECMA International** in 1996 for standardization.
- In **1997**, the first official standard, **ECMAScript (ECMA-262)**, was published.
- **ECMAScript** serves as the standardized specification for JavaScript.  
  Modern JavaScript is an **implementation of ECMAScript**.

---

## 5. How did Netscape, Sun Microsystems, and Microsoft contribute to JavaScript’s evolution?

- **Netscape**: Created and embedded JavaScript in its browser (Netscape Navigator).
- **Sun Microsystems**: Owned the Java trademark and collaborated with Netscape to name the language **JavaScript**.
- **Microsoft**: Created its own version of JavaScript called **JScript** for Internet Explorer, leading to compatibility issues and fragmentation between browsers.

These contributions and conflicts led to the need for a standardized version (ECMAScript).

---

## 6. What was the browser war, and how did it impact JavaScript?

The **browser war** was a period of intense competition during the late 1990s between:
- **Netscape Navigator** and
- **Microsoft Internet Explorer**

### Impact on JavaScript:
- Each company developed its own JavaScript engine (Netscape’s SpiderMonkey, Microsoft’s JScript).
- They introduced **non-standard features**, leading to **cross-browser compatibility problems**.
- The fragmentation highlighted the need for **standardization**, which resulted in the creation of **ECMAScript**.
- This era also slowed JavaScript’s progress due to inconsistent implementations.
